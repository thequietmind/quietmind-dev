# Keyboard Shortcuts

The following guide documents the keyboard shortcuts that ship with our Phoenix config and our dotfiles config, as well as a few shortcuts that are handy to have alongside this collection, like some of the default VS Code shortcuts that we use the most. It also notes the custom Zoom shortcuts we typically configure on a new system, so we don't forget.

## Phoenix Window and App Manager

> Please note: The <kbd>hyper</kbd> key is the Caps Lock key.

### Resize Window into Halves

| Shortcut                                           | Description                             |
| -------------------------------------------------- | --------------------------------------- |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>↑</kbd> | Move window to the top half of screen   |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>→</kbd> | Move window to the right half of screen |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>↓</kbd> | Move window to the bottom half          |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>←</kbd> | Move window to the left half            |

### Resize Window into Quadrant Corners

| Shortcut                        | Description                            |
| ------------------------------- | -------------------------------------- |
| <kbd>hyper</kbd> + <kbd>q</kbd> | Move window to the top-left corner     |
| <kbd>hyper</kbd> + <kbd>w</kbd> | Move window to the top-right corner    |
| <kbd>hyper</kbd> + <kbd>a</kbd> | Move window to the bottom-left corner  |
| <kbd>hyper</kbd> + <kbd>s</kbd> | Move window to the bottom-right corner |

### Resize Window into Percentage Sides

| Shortcut                                           | Description                                           |
| -------------------------------------------------- | ----------------------------------------------------- |
| <kbd>hyper</kbd> + <kbd>[</kbd>                    | Move window to left percentage of screen              |
| <kbd>hyper</kbd> + <kbd>]</kbd>                    | Move window to right percentage of screen             |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>[</kbd> | Move window to opposite of left percentage of screen  |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>]</kbd> | Move window to opposite of right percentage of screen |

### Center Window

| Shortcut                                             | Description                  |
| ---------------------------------------------------- | ---------------------------- |
| <kbd>hyper</kbd> + <kbd>c,c</kbd>                    | Center the window            |
| <kbd>hyper</kbd> + <kbd>shift</kbd> + <kbd>c,c</kbd> | Center and resize the window |

> Note: Double press the <kbd>c</kbd> key.

### Move Window to Space

| Shortcut                        | Description                           |
| ------------------------------- | ------------------------------------- |

| <kbd>hyper</kbd> + <kbd>r</kbd> | Move focused window to next screen    |

## System Commands

### Screenshots

| Shortcut                                                               | Description                      |
| ---------------------------------------------------------------------- | -------------------------------- |
| <kbd>command</kbd> + <kbd>shift</kbd> + <kbd>3</kbd>                   | Capture the entire desktop       |
| <kbd>command</kbd> + <kbd>shift</kbd> + <kbd>4</kbd>                   | Capture a portion of the desktop |
| <kbd>command</kbd> + <kbd>shift</kbd> + <kbd>4</kbd>, <kbd>space</kbd> | Capture a window or menu         |
| <kbd>command</kbd> + <kbd>shift</kbd> + <kbd>5</kbd>                   | Open screenshot panel            |
| <kbd>command</kbd> + <kbd>shift</kbd> + <kbd>6</kbd>                   | Capture touch bar                |

> Add <kbd>control</kbd> to any of the screenshot keyboard shortcuts above to copy to the clipboard instead of saving a file.
>
> For <kbd>command</kbd> + <kbd>shift</kbd> + <kbd>4</kbd>, hold <kbd>space</kbd> to move the selection, <kbd>shift</kbd> to lock one axis, or <kbd>option</kbd> to resize from the center.
